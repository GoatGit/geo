# 01 · 产品功能规格

## 1. 信息架构

产品为 Web 控制台（桌面优先，响应式兼容平板），以**品牌（Brand Workspace）为工作空间单位**。

```
登录 / 注册
└─ 控制台
   ├─ 品牌切换器（全局，左上角）
   ├─ ① 总览          首页仪表盘：品牌健康卡 + 今日关键指标 + 待办引导
   ├─ ② 监测
   │    ├─ 排名透视        核心指标卡 / 品牌排名榜单 / 排名趋势 / 全景排名矩阵
   │    ├─ 竞品透视        竞品提及率榜单 / 分引擎对比矩阵 / 竞品发现
   │    ├─ 引用源分析      引用源追溯明细 / 信源平台偏好 / 缺口洞察(P1)
   │    └─ 快照存证        采集快照检索、预览、导出（截图/原文/录屏）
   ├─ ③ 口碑
   │    └─ 口碑分析        情感分布与趋势 / 印象词对照 / 原文引用证据
   ├─ ④ 监测配置
   │    ├─ 监控问题管理    问题分组 / 排名词·口碑词 / 批量导入 / AI 拓写
   │    ├─ 识别口径管理    识别词 / 别名 / 竞品与竞争点（口径的单一事实源）
   │    └─ 采集状态        引擎覆盖、任务队列健康度、配额用量
   ├─ ⑤ 报告中心        周报 / 月报 / 诊断报告：列表、生成状态、在线预览、PDF 导出
   ├─ ⑥ 诊断（按次付费）  任意品牌一次性诊断：配置 → 支付 → 队列 → 报告
   └─ ⑦ 账户与套餐       套餐对比与订阅 / 积分余额与消耗明细 / 账单 / 成员管理(P2)
```

**与竞品 IA 的差异**：不设"优化/AGENT"两个一级模块；"采集状态"页为新增（竞品把队列藏在排名页浮层，我们是独立页，呼应"透明可信"定位）；"识别口径管理"升级为一级入口（口径是该品类的命门，竞品埋得太深导致用户失配——见 00 文档教训 #1）。

### 命名对照表（原创命名 vs 竞品命名）

| 概念 | 竞品命名 | 我们的命名 |
|------|---------|-----------|
| 三率转化视图 | 三率漏斗 | **可见性漏斗**（提及 → 上榜 → 首推） |
| 问题×引擎排名表 | 全景排名矩阵 | **引擎×问题位次矩阵** |
| 引用缺口热力图 | 信源阵地热力图 | **引用缺口地图**（我方/竞对/空白三类） |
| 识别词/竞品名管理 | 监控识别管理 | **识别口径管理** |
| 印象词对照 | 巩固/攻坚 | **优势印象 / 待攻印象** |
| 行动建议表 | 优先级行动建议 | **行动清单**（P0/P1/P2） |
| 单次诊断 | 单次品牌诊断 | **快速体检**（按次付费） |
| 快照下载 | 搜索快照下载 | **快照存证** |

## 2. 核心对象模型（产品视角）

```
账号 Account
 └─ 品牌 Brand（工作空间，订阅按品牌开通）
     ├─ 监控问题 MonitoringQuestion（类型：排名词 | 口碑词；分组；AI 拓写原文/改写文）
     ├─ 识别口径 RecognitionProfile
     │    ├─ 本品识别词 + 相似别名（如"小米汽车" + [SU7, YU7, 小米SU7…]）
     │    └─ 竞品条目（名称 + 别名 + 竞争点备注）
     ├─ 采集计划 CollectionPlan（引擎 × 端 × 频率 × 问题集）
     │    └─ 查询任务 QueryTask（问题 × 引擎 × 端 × 轮次，原子单位）
     ├─ 数据资产：回答原文 / 快照 / 抽取结果 / 日指标 / 周期指标
     └─ 报告（周报 / 月报 / 快速体检）
```

**配额模型**：`问题数配额`（按排名词/口碑词分池）× `引擎端配额`（网页端 N 个引擎、APP 端 M 个）× `频率`（全档位每日 1 轮，见 02 §7.1）。积分（Credit）用于超套餐动作：快速体检、历史导出、APP 端补查。

## 3. 模块规格

### 3.1 品牌初始化（关键首次体验）

**流程**：输入自然语言品牌描述（或官网 URL）→ AI 解析（展示实时进度：正在检索品牌资料 / 正在生成简介 / 正在建议识别词）→ 产出品牌档案草稿 → **用户确认识别口径**（识别词 + AI 建议别名 + AI 建议竞品，全部可增删）→ 引导添加监控问题。

规格要点：
- AI 解析产出：行业、官网、品牌简介、**建议识别词与别名**（从产品线名、商品名中抽取）、**建议竞品清单**（含一句话竞争点）。
- 教训 #1 对策：别名建议必须包含"品牌 × 自有产品线名"（如 小米汽车 → SU7/YU7），默认勾选。
- 引导页内嵌 3 步骤说明（配品牌 → 配问题 → 看排名），首次进入总览页显示采集预计完成倒计时。

### 3.2 监控问题管理

- 批量添加（每行一条），逐条标记类型：**排名词**（"有哪些推荐"类）/ **口碑词**（品牌评价、风险类）。默认 AI 自动分类并展示分类理由，可改。
- **AI 拓写**开关：把短词改写为自然问法（"电动汽车排名" → "我想买一辆电动车，有什么推荐的吗？"），保留原文与改写文两份，指标口径用改写文采集。
- 配额按类型分池显示（排名词 x/y · 口碑词 m/n），超限时新增按钮置灰并给出升档指引（不弹窗打断）。
- 分组（如"轿车类/SUV类/口碑类"）支持排序；删除/修改问题后**历史数据保留**，仅停止后续采集。
- 教训 #4 对策：采集配置页常驻两类问题的进度环，避免"口碑模块空转"的隐蔽隔离。

### 3.3 排名透视（核心页）

页面结构（自上而下）：

1. **指标卡组**：提及率 / Top3 率 / 首推率 / 平均名次。每卡：当日值、分子/分母（点击下钻到问题清单）、近 7/30 天迷你趋势、口径说明 tooltip。周期选择器**默认自适应**（无当日数据则自动回退到最近有数据日，并提示）。
2. **品牌排名榜单**：按单问题查看 AI 推荐列表，本品行高亮 + 别名合并；显示每引擎分列位次。
3. **引擎×问题位次矩阵**：行=问题，列=引擎，单元格=位次徽章（#1 绿 / 未上榜 红），行尾聚合列（综合名次、三率）。支持按聚合列排序、导出 Excel。
4. **可见性漏斗**：提及 → 上榜 → 首推的嵌套转化条（口径见 02 §2）+ 各段损失的问题数清单（点击展开）。
5. **采集队列实时面板**（页角固定入口）：展示进行中的查询任务（引擎 × 问题）、成功/失败/重试计数、当前账号池健康度摘要。这是"可信"定位的可见性锚点。

### 3.4 竞品透视

- **竞品榜单**：竞品 × 出现次数 / 提及率 / Top3 率 / 首位率，本品置顶标记。
- **分引擎对比矩阵**：竞品行 × 引擎列（提及/Top3/首位三指标切换）。
- **竞品发现**：从采集回答中自动抽取高频品牌（含出现次数与出现的问题分布），进入"待确认池"，一键采纳为竞品或忽略；**自家别名自动排除**（基于识别口径，教训 #1 对策的落地页）。
- 竞品对比口径声明：与本品同批查询、同批问题，同口径解析。

### 3.5 引用源分析

- **引用源追溯**：明细表（信源平台 / 被引次数 / 覆盖引擎 / 示例原文摘录 / 链接），筛选（问题/引擎/日期/是否自有域名），支持导出。空态显示管道进度（教训 #6 对策）。
- **信源平台偏好**：TOP 平台条形图（按引擎堆叠）、各引擎取材构成占比、自有域名被引趋势。
- **引用缺口地图**（P1）：平台类型 × 引擎矩阵，格值=被引次数，三色标注（我方主导 / 竞对主导 / 空白），点击格查看该格被引明细与"建议动作"（规则引擎生成，如"空白 × 高频引擎 → 建议优先在该类平台布局结构化内容"）。

### 3.6 口碑分析

- 范围：仅"口碑词"问题的采集结果。
- 输出：情感分布（正/中/负，含口径：按回答条数）、情感趋势、**印象词对照表**（优势印象 vs 待攻印象，词 + 出现回答数，点击查看原文摘录与跳转快照）。
- 每个结论附原文证据（"AI 原话"引用块 + 引擎 + 日期 + 快照链接）。
- 情感判定由模型批量抽取（见 05 文档），**页面显示模型置信度抽样审计入口**（人工抽检 5% 标注，用于校准 prompt——这是口径可信度的一部分）。

### 3.7 快照存证

- 检索：问题 / 引擎 / 端 / 日期。列表项含回答原文、AI 摘要、引用链接列表。
- 每条采集记录绑定：**回答原文 JSON + 页面截图 + （网页端）录屏片段 + 请求元数据哈希**。
- 快照保留 7 天（可配置），到期前 3 天在报告页提示导出；导出 Excel/PDF 走积分。
- **报告证据归档**：周报/月报/体检报告生成时，把报告引用到的证据包（原文摘录/截图/证据卡）复制进报告 payload 归档——报告可回溯性不受快照 7 天保留期约束（对应 06 §5 验收 #1）。

### 3.8 报告中心

- **周报**（每周一自动生成上周数据）/ **月报**（每月 1 日生成），生成状态可见，失败可重试。
- 报告结构（自有版式）：品牌体检总览（8 指标 + 健康标签）→ 位次表现（矩阵摘录 + 问题分层表）→ 可见性漏斗归因 → 竞品格局 → 口碑 → 引用源与缺口 → 行动清单（P0/P1/P2）→ 附录（口径说明与方法论）。
- 在线预览 + PDF 导出；支持"去品牌化"水印开关（Agency 场景，P2）。
- **首次报告引导**：无报告时显示生成时间表 + "把监测面配完整"的任务清单。

### 3.9 快速体检（按次付费，P2）

- 输入品牌描述（无需建品牌、无需订阅）→ 选择问题数 × 引擎端 → 积分估价器（实时算消耗）→ 支付 → 队列（约 1-3 小时）→ 只读分享报告页（带水印，可设置有效期）。
- 估价公式：`Σ(问题数 × 各引擎端单价)`，积分单价与档位见 02 文档 §7。

### 3.10 账户与套餐

- 套餐档位（初始定价，见 02 文档 §7）：免费版 / 入门 / 标准 / 专业 / 定制。
- 套餐页显示：当前档位、**按类型分池的问题配额条**、引擎端覆盖、频率、积分余额、近期账单。
- 配额超限采用**非阻断式引导**：进度条变警示色 + 文案给出"升档可增加 N 个问题位"，不做全屏弹窗。

## 4. 关键用户流

### U1 新用户首次出数（目标 ≤ 10 分钟见真数据）

```
注册登录 → 创建品牌(自然语言) → 确认识别口径(1步，AI预填)
→ 批量粘贴问题(AI分类+拓写) → 确认采集范围(默认全选网页端引擎)
→ 总览页显示"采集中 n/m"实时进度 → 完成后指标卡点亮 → 引导查看矩阵与生成首份基线
```

### U2 日常监测（品牌运营）

```
打开总览 → 看今日指标与昨日差值 → 下钻异常指标(分子/分母→问题清单→原文/快照)
→ 查看行动清单 → 导出周报发给上级
```

### U3 Agency 多品牌（P2）

```
账号下多个品牌工作区 → 品牌切换器秒切 → 报告去品牌化导出 → 成员权限(品牌隔离)
```

### U4 快速体检（提案场景）

```
输入竞品客户的品牌描述 → 估价 → 支付积分 → 等待队列 → 只读分享链接交付
```

## 6. UI 设计方向（原创，不像素级复刻）

- **视觉基调**：深色侧栏 + 浅色工作区的双区布局（与竞品的"浅色图标栏"形成差异）；主色采用**青蓝色系**（区别于竞品紫罗兰），语义色自成体系。
- **设计语言**：信息密度优先的"数据工作台"风格——紧凑表格、单色系图表 + 单一强调色、等宽数字字体；弱化装饰性插画，强调数据与证据（原文引用块、时间戳、口径徽章是视觉主角）。
- **独有组件**：口径徽章（点击浮层显示分子/分母定义）、证据卡（原文摘录 + 引擎 + 快照缩略）、采集队列磁贴。
- **图表规范**：统一图表色板按引擎分配（内部规范，避免使用竞品的引擎配色映射）；矩阵徽章色阶 ≤ 4 档。
