# 04 · 采集引擎设计（核心壁垒）

> 这是产品"神"之所在：数据可信度与成本曲线由本模块决定。设计目标：**稳定、拟人、可存证、成本可控**。同时明确：本模块的全部手段存在平台协议对抗属性，法务与运营风险见 06 文档 §4。
> **落地形态（v2）**：浏览器基础设施采用无影 AgentBay `browser_latest` 镜像（会话制，CDP 接入）；账号态经 Browser Context 跨会话持久化（替代自建 Profile 目录）；本文的账号池、拟人化、存证链、调度设计均不变，基础设施差异见 07 文档。

## 1. 总体结构

```
                ┌─────────────────────────────┐
 Orchestrator ──► QueryRun 任务 (brand-blind)  │   Worker 拿到的任务不含品牌业务信息
                └──────────────┬──────────────┘   只有：引擎/端/问题文本/轮次ID
                               ▼
        ┌──────────────────────────────────────────────┐
        │              采集 Worker                      │
        │  ┌────────────┐ ┌────────────┐ ┌──────────┐ │
        │  │ 会话管理器   │ │ 引擎适配器  │ │ 存证记录器│ │
        │  │ AccountSession│ │EngineAdapter│ │EvidenceRecorder│
        │  └──────┬─────┘ └──────┬─────┘ └────┬─────┘ │
        └─────────┼──────────────┼────────────┼───────┘
                  ▼              ▼            ▼
           账号池服务        引擎通道      对象存储 + QueryRun 落库
        (Account Pool)  (Web / App)   (原文/截图/录屏/元数据)
```

**分层原则**：编排器懂业务（配额、口径），Worker 不懂业务；引擎适配器屏蔽"网页端/APP 端"差异；账号池与会话管理是所有通道的公共设施。

## 2. 引擎适配层（Engine Adapter）

统一接口：

```ts
interface EngineAdapter {
  engine: EngineId;                 // 'doubao' | 'deepseek' | 'wenxin' | 'qwen' | 'yuanbao' | ...
  surface: 'web' | 'app';
  ask(ctx: SessionContext, question: string, opts: AskOptions): Promise<AskResult>;
  healthCheck(): Promise<AdapterHealth>;
}

interface AskResult {
  status: 'ok_with_answer' | 'ok_empty' | 'failed';
  answerText: string;              // 回答正文（Markdown 归一化）
  rawPayloadRef: ObjectRef;        // 原始响应/页面归档指针
  citations: RawCitation[];        // 回答附带的引用卡片/链接（能取多少取多少）
  timing: { queuedAt; firstTokenAt; completedAt };
}
```

### 2.1 网页端通道（P0）

两条技术路线，按引擎情况组合：

| 路线 | 适用 | 实现 | 优劣 |
|------|------|------|------|
| A. 浏览器自动化 | 全部网页端引擎（兜底） | Playwright + Chromium 常驻会话，DOM 选择器 + 回答流式监听 | 稳定通用；成本高（内存/并发低），需对抗页面改版 |
| B. 会话内接口调用 | 部分引擎的对话接口 | 复用登录态 token 直接请求对话接口 | 成本低速度快；接口变更风险高、风控更敏感 |

实现要点：
- **适配器版本化**：每个引擎适配器带 `schemaVersion`，页面改版只需发新适配器版本；QueryRun 记录所用版本，历史数据可解释。
- **回答完成判定**：流式输出停止 + DOM 稳定窗口（如 3s 无新增）+ 引擎"停止生成"控件消失，三条件与。
- **引用抽取**：网页端引用卡片 DOM 直接结构化抓取；散落在正文中的链接正则提取 + 去噪。
- **录屏**：Playwright video 按会话录制，单问题裁剪片段；仅保留最近 7 天（可配置）。

### 2.2 APP 端通道（P1，差异化壁垒）

| 组件 | 方案 |
|------|------|
| 设备池 | 云真机平台租用 + 自建安卓模拟器农场混合；按引擎-版本固定设备画像 |
| 自动化 | adb + UiAutomator / Accessibility 服务脚本；模板匹配定位输入框与发送键 |
| 回答采集 | 无障碍树文本抽取 + 屏幕连续截帧；引用卡单独截屏 |
| 网络归因 | 代理网关按设备分配出口，记录出口 IP |
| 版本管理 | APP 升级灰度期间锁版本（不自动更新），适配新版后灰度切换 |

APP 端成本为网页端 2-4 倍，计费倍率（4 分/查 vs 2 分/查）由此而来；高成本引擎（多模态/长回答）8 分/查。

## 3. 账号池服务（Account Pool）

### 3.1 账号生命周期

```
注册 → 实名/绑定(按平台要求) → 养号期(7-14天低频真实行为) → 可用 → 轮换使用
   → 风控触发(降频/冷却) → 封禁 → 回收归档
```

### 3.2 核心机制

- **账号档案**：`{平台, 端, 注册渠道, 设备画像, 常用出口IP段, 健康分, 近7日使用次数, 状态}`。
- **健康分模型**：连续成功 +1，风控验证 −5，失败 −2，单日使用 > 阈值 −1；低于阈值自动进入冷却（如 72h），低于 30 分退役。
- **会话粘性**：同一账号绑定固定设备画像 + 出口 IP 段（IP 跳变是主要封号诱因）；v2 落地 = AgentBay Browser Context（登录态/存储持久化）+ BrowserOption 固定指纹参数 + 会话粘性住宅代理（07 §4.2）。
- **配额内化**：每账号每引擎每日提问上限（如 20 次），超限强制轮换——单账号高频同构提问是风控特征。
- **去个性化**：账号不带任何品牌方关联信息；不关注、不搜索品牌相关内容；提问历史仅来自本次监测问题集（且跨品牌打散）。
- **供给运营**：注册通道、接码、实名资源是持续成本项；账号池规模按"日查询量 ÷ 单账号日上限 ÷ 安全系数(0.6)"估算，并保持 20% 冗余。

### 3.3 代理与出口

- 住宅代理池按地域分组；会话级粘性出口（一次 QueryRun 全程同一出口）。
- 出口质量评分：延迟、封禁率、验证码触发率，低分自动摘除。
- 禁止数据中心 IP 直连C端产品（风控重点特征）。

### 3.4 拟人化节奏

- 输入速度：逐字输入 + 随机抖动（非 fill 瞬间注入）。
- 会话间隔：同账号两次提问间隔服从对数正态分布（分钟级），同品牌任务跨账号打散。
- 每日总量按地域时区分布（白天重、夜间轻）。

## 4. 存证链（Evidence Chain）——可信度的技术表达

每条 QueryRun 产出证据包：

```
evidence/
 └─ {runId}/
    ├─ answer.json          # 归一化回答正文 + 引用列表
    ├─ raw.html / raw.mhtml # 网页端页面归档（APP端：截帧序列）
    ├─ screen.mp4           # 会话录屏片段（7 天保留）
    ├─ meta.json            # 引擎/适配器版本/账号指纹(哈希)/出口IP/时间轴/问题原文哈希
    └─ integrity.sha256     # 以上文件的内容哈希清单
```

规则：
- 证据包一经写入**只读**（对象存储 WORM 策略），删除仅按保留期过期。
- 前端任何数据点可跳转到证据卡：原文摘录高亮命中片段 + 快照缩略 + 时间戳。
- "分享只读报告"里引用的每个数字附带证据卡引用（脱敏账号信息）。

## 5. 调度与限流

- **轮次触发**：品牌级 cron（全档位每日 1 轮，时间在品牌时区白天随机化；2026-09 定价决策：取消专业版每日 2 轮）。
- **优先级队列**：快速体检(付费加急) > 专业版 > 标准 > 入门 > 免费版；同优先级按品牌轮转 fair-share。
- **引擎限流器**：每引擎令牌桶（并发 + QPS + 日配额）；触发平台风控信号（验证码率突增）自动降速 50%。
- **熔断**：引擎 5 分钟失败率 > 30% → 暂停派发 + 告警 + 前端采集状态页横幅（"某引擎通道维护中，本轮该引擎数据将延迟"）。
- **重试**：失败重试最多 2 次，必须更换账号与出口；重试后仍失败标记 `failed`，不计入分母。

## 6. 成本模型（决定定价下限）

| 成本项 | 估算（网页端/次） | 说明 |
|--------|------------------|------|
| 浏览器会话 | ¥0.007-0.02 | AgentBay 会话积分（≈¥0.6/会话小时 × 30-90 查询/会话小时）；自建池方案为 ¥0.02-0.05 |
| 代理流量 | ¥0.01-0.03 | 住宅代理按流量 |
| 账号摊销 | ¥0.02-0.08 | 注册/接码/封损率 5-15% 分摊 |
| 存储存证 | ¥0.005 | 截图+录屏 7 天保留 |
| LLM 解析 | ¥0.01-0.03 | 小模型批量抽取 |
| **网页端合计** | **≈ ¥0.05-0.16/次** | 售价 ¥0.1/积分 × 2 积分 = ¥0.2/次（02 §7.2）；订阅档位按配额使用率单独核算（06 §3） |
| APP 端合计 | ≈ ¥0.3-0.8/次 | 云真机/云手机（P1 评估 AgentBay 云手机镜像）时长为主；定价 4-8 积分覆盖 |

规模效应主要在：账号自注册产能、代理包月、Worker 密度。

## 7. 失败模式手册（Runbook 预案）

| 故障 | 表现 | 预案 |
|------|------|------|
| 页面改版 | 适配器成功率骤降 | 适配器热修 + schemaVersion 升级；期间该引擎任务转 `failed`（不污染口径） |
| 风控收紧 | 验证码率/封号率突增 | 自动降速、账号池冷却扩容、切换注册渠道 |
| 接口配额耗尽 | 大面积 `ok_empty` | 与 `failed` 区分：空回答率 > 阈值触发引擎熔断，人工核查（教训 #5） |
| 云真机故障 | APP 端任务积压 | 队列自动漂移到备用设备池；超过 SLA 延迟公示 |
| LLM 解析异常 | 抽取字段缺失 | 抽取结果带 `parserVersion`，可全量重放；解析失败进入死信队列人工处理 |
