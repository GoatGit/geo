## 一句话定位

帮品牌方回答一个问题：**"当用户问 AI 时，我的品牌被推荐了吗、排第几、AI 引用了谁的内容"** —— 并用可回溯的证据链证明每一个数字。

## 范围边界（重要）

**做**：多引擎中立监测、排名/竞品/引用源/口碑分析、监控问题与识别词管理、搜索快照存证、周报月报、单次品牌诊断、订阅+积分计费。

**不做**（明确裁剪）：发稿/信源库等供给侧功能、对话式 Agent、媒体渠道合作、内容营销矩阵、外部机构合作背书。

## 设计原则（复刻"神"，不抄"形"）

1. **采集底座是一等公民**：账号池、风控对抗、过程存证是产品护城河，架构上最先设计、最难替代。
2. **口径透明**：每个指标都能下钻到分子/分母，每条数据可回放到原始回答与快照。
3. **原始回答永不留空**：采集失败≠数据为 0，失败与空是两种状态，UI 与存储严格区分。
4. **文案、视觉、命名全部原创**：指标名可用行业通用词（提及率/Top3 率为通用概念），但文案、图标、布局、配色、报告版式均为自有设计；不复制任何竞品页面文本与素材。
