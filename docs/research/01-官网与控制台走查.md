# 调研存档 01 · 透镜GEO 官网与控制台全站走查

> 内部调研资料，仅作设计参考。**禁止**复制其中的文案、命名、版式用于我们的产品。
> 调研方式：浏览器实测（未登录 + 登录后），日期 2026-09-14。

## 1. 产品基本信息

- 产品：透镜GEO（geo.timus.cn），运营方：北京时光不语科技有限公司
- 定位："AI 搜索品牌数据检测与智能决策平台"，2.0 叙事为"从中立监测工具升级为 GEO 优化闭环平台"
- 五步闭环叙事：中立监测 → 洞察建议 → 循证写作 → 精准发稿 → 效果归因
- 官网公布数据：每日 5 万+ 中立模拟提问；8 大 AI 引擎端；3000 万+ 引用源数据；11 万+ 发稿渠道
- 覆盖引擎（官网 /ai 页）：豆包、DeepSeek、文心一言、通义千问、腾讯元宝、Kimi
- 信任背书：与新华社国家重点实验室战略合作（内容安全/过程存证）

## 2. 官网结构与转化漏斗

- 首页 hero 即输入框：品牌自然语言描述 + 快速填入示例 chips（小鹏汽车/完美日记/格力空调/维乐口腔）→ 提交后弹手机号验证（左半深色区重申三大价值点：跨模型实时监测/竞品对比分析/绝对中立查询）
- 导航：首页/单次诊断/定价/洞察报告/文章/资讯/联系我们/关于我们(实为 changelog)/开始试用/登录
- 内容营销矩阵：文章按"入门指南/实战方法/指标测量/平台观察"分类，标题为长尾问题式（如"为什么天天发公关稿，AI 搜索里还是搜不到自己品牌？"）；行业报告（月度 AI 信源分析：宣称 5 引擎、22 行业、2100+ 品牌、15 万次问答、2263 万条引用）
- **/ai 页面（AI Instructions）**：公开 llms.txt、声明对 AI 爬虫开放、列"欢迎引用的事实要点"，原文"被 AI 读懂，是被 AI 引用的前提——这正是我们建议每一位客户做的第一件事"。是自身方法论的 dogfooding 展示。

## 7. 控制台信息架构（登录后）

左侧图标一级栏：**品牌 / 报告 / 排名 / 口碑 / 优化 / AGENT** + 诊断 / 套餐 / 头像；顶栏全局元素：品牌切换器、侧栏"数据状态：全部正常 · 数据更新至 09/14"。品牌为工作空间单位。

### 7.1 品牌
品牌档案与参考资料（"写稿、问答、洞察分析时 AI 自动调用"）；已认证品牌徽章；识别名管理；添加资料（PDF/URL/文本）；资料 tabs 全部/文档/链接/文本。

### 7.2 报告（首页）
品牌头图卡（头像/暂无采集/行业 tag/官网/0 识别词/8 监控问题/0 竞品；当日采集查询/引用源/已发稿件；统计日期与更新时间）+ 快捷动作四卡（挖掘监控问题"对话式补全监测面"、AI 撰写稿件"写作Agent·挂载知识库"、信源库"监控×价格·按被引成本推荐"、AI排名透视"实时位次·逐题下钻"）+ 周报/月报 tabs + "首份报告生成中"空态 + 报告模板（标准版）。

### 7.3 排名（二级导航）
- 主：AI排名透视 / AI竞品透视 / 引用源追溯
- 分析组：信源平台偏好 / 引用源洞察（付费锁）
- 管理组：监控问题管理 / 监控识别管理 / 搜索快照下载

**AI排名透视**：指标卡（品牌提及率/Top3推荐率/首位推荐率，分子/分母 0/0）+ 统计周期（默认 09-13）+ AI引擎/监控问题筛选 + 导出（带积分图标）；品牌排名区（排名榜单+修正品牌名、排名趋势近7天、全景排名矩阵：日期选择/显示列/导出）。

**监控问题管理**：配额头（总占用 8/3、本页·排名词 4、✦待释放 0、扩容按钮）+ 列表（监控类型"排名词"标签/问题/分组下拉/添加时间/状态"监控中"/编辑删除）+ 搜索/导出(积分)/导入问题/增加新问题（超限置灰）+ 分组 tabs。

**监控识别管理**：识别词 tab（识别词"必填，剩余修改次数 3 次" + 相似识别词"已登记 N 个别名，监控/排名统计时合并"）+ 竞品名 tab（名称/主要竞争点/相似别名）+ 品牌档案（所属行业/官网/品牌简介）。标语："告诉 AI 哪些说法算「你」、哪些算「对手」，榜单与统计口径由此决定"。

### 7.4 口碑
AI口碑分析（问题 chips + AI平台筛选 + 情感倾向分布[评级/正中负占比] + 情感走势 + 正面评价/中性描述 tabs + 平台/大模型原文引用表）+ 引用源追溯 + 管理组。**空数据时评级直接显示红色"高风险"**。

### 7.5 优化
- 信源库：全库 143,501 家，"在这些源上发的内容，更容易被 AI 引用 · 引用数据来自监测底座"；筛选（AI引擎/监控问题/媒体类型/收录类型新闻源·网页/积分消耗区间/账号认证/地区媒体分类）；搜索按媒体账号/信源平台维度；表格（媒体/类型/收录情况/出稿率/引用指数/价格✦/发稿按钮/收藏）；**备注列长文本竖排溢出的布局 bug**
- 发布稿件：付费墙页（"好内容，要发到 AI 会引用的地方"+ 四步流程：多媒体稿件编辑→一键多平台分发→收录回执→引用归因）
- 发稿记录 / 稿件追踪（均为付费墙）

### 7.6 AGENT
对话式首页："今天想让 Agent 帮你做什么？"（查数据，找问题，制定优化计划）；三模式 pill：优化策略/问题挖掘/撰写稿件；大输入框（"问我 GEO 表现、行业热点、信源选择或内容引用…"）+ **可用余额 0 徽章** + 开始按钮（**0 积分时禁用**）；"大家在问"6 个建议问题；侧栏：新建对话/Agent知识库/稿件库/最近记录。

### 7.7 套餐
当前套餐卡（免费体验版；监控问题配额 8/3 **红色超限条**；覆盖大模型平台 3/3）+ 账户积分 ✦0 + 充值按钮 + 五档订阅卡 + "监控会员套餐按品牌独立开通 · 可用账户积分或现金支付"。

## 8. 版本公告（V2.8.0，2026-09-11）反映的迭代方向

- 新增：监控问题删除/修改后仍可查历史数据；引用源追溯按筛选结果导出
- 问题管理：分组排序、删除体验优化
- 快照：APP 端文本快照结构优化；图片/录屏快照"保留 7 天"文案
- 稿件：编辑器与稿件追踪优化
→ 推断其近期重心在**口径稳定性（历史可查）、引用源下钻、快照体系**。

## 9. 走查中发现的产品缺陷（教训清单）

1. 活动公告弹窗图片裂图（仅 alt 文本）
2. 信源库表格备注列竖排文字溢出破坏行高
3. 定价页整页滚动时导航+标题重复渲染 3 次（疑似 sticky header 与动画冲突）
4. 口碑页空数据直接显示红色"高风险"评级（零数据≠高风险）
5. 登录页对记忆手机号自动发送验证码
6. 免费版配额 3 问题但示例品牌预置 8 个问题，套餐页直接呈现 8/3 超限红条（onboarding 与配额冲突）
7. 统计周期默认"昨日"，新用户首屏全 0，需手动切"今日"
8. 报告页品牌头图数据来自凌晨快照，与排名页实时数据不一致（"暂无采集"与 40 条查询并存）
9. 引用源提取明显滞后于排名提取，空态无进度解释
10. 免费试用页/控制台多处元素对自动化语义点击无响应（疑似透明遮罩，坐标点击可过）——顺带说明其前端存在不可见覆盖层
